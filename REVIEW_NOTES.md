# Review notes

This rebuild is an independent React/Vite implementation.

Current feature set:
- 78-card Major and Minor Arcana library
- One, three, and five card practice spreads
- Upright and reversed reading prompts
- Image-first blind reading that hides card titles until reveal
- Daily card
- Five selectable visual themes
- Deck-style selector and per-card custom image URLs
- Learning path, historical research links, journal, and saved readings

Storage is local to the browser. No accounts or paid backend are required. This preview branch is isolated from main. Cloudflare production deployments are disabled; only this branch is configured for preview deployment.

The built-in art is an original symbolic study treatment, not licensed deck scans. This is a first functional version for review, and additional refinement can follow based on testing and feedback.
